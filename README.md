# LRS Safety Board

Live page: https://lrsimoes.github.io/SAFTEY-BOARD/ (TV: add `#tv`)

Shows LR Simoes Steelwork staff medicals and site inductions. Updated on the 1st of each month from the OneDrive Health & Safety folder.

- `data/staff.json`, `data/attention.json`, `data/scan.json`: the data
- `build/template.html`: the page
- `python3 build/build.py`: rebuilds `index.html` from the two
